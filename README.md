# PaperLoom（文脉）

> 会记得你、也会记得你整个文献库的 Zotero 研究助手

现有 Zotero 插件本质是「把当前论文塞进 prompt，问一句答一句」——无状态、单文档、不主动。

PaperLoom 把三件事做成一个闭环：

```
对话 ──抽取──▶ 记忆 / 跨论文知识图谱
 ▲                  │
 └────注入 / 主动提示────┘
```

- **记忆**：记住你的阅读偏好（比如「这篇我没读过，讲简单点」），并能在后续回答中真正生效、且可见。
- **知识图谱**：随着对话自动生长，跨论文连接概念、论断与矛盾，每条边都能点回原文页码。
- **预处理（第二阶段）**：新论文入库时提前算出增量，在你长时间停留在某一页、或问到相关段落时，以可忽略的 tip 形式浮现。

## 配置大模型

两种入口，效果相同：

- **工具 → PaperLoom → 设置…**（不依赖 Zotero 设置面板，任何版本都能用）
- Zotero 设置 → PaperLoom → 点「打开 PaperLoom 设置」

可配置：API Base URL（OpenAI 兼容，填到 `/v1`）、API Key、对话模型、抽取模型、`max_tokens`、`temperature`、超时、结果缓存、数据目录。
窗口里的「测试连接」会发一条 16 token 的 ping，用来确认接口地址、鉴权和模型名是否有效。

配置只写入本机 Zotero 偏好（`extensions.paperloom.*`），不会上传。
