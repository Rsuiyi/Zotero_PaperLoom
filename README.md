# PaperLoom（文脉）

> 会记得你、也会记得你整个文献库的 Zotero 研究助手

现有 Zotero 插件本质是「把当前论文塞进 prompt，问一句答一句」——无状态、单文档、不主动。

PaperLoom 把三件事做成一个闭环：

```
对话 ──抽取──▶ 记忆 / 跨论文知识图谱
 ▲                  │
 └────注入 / 主动提示────┘
```

- **记忆**：记住你的阅读偏好（比如「这篇我没读过，讲简单点」），并能在后续回答中真正生效、且可见。
- **知识图谱**：随着对话自动生长，跨论文连接概念、论断与矛盾，每条边都能点回原文页码。
- **预处理（第二阶段）**：新论文入库时提前算出增量，在你长时间停留在某一页、或问到相关段落时，以可忽略的 tip 形式浮现。

## 配置大模型

两个入口，内容是同一份界面：

- **Zotero 设置 → PaperLoom**（内嵌完整设置）
- **工具 → PaperLoom → 设置…**（独立窗口）

配置分三步，和 PDF2zh 的模型管理思路一致：

1. **新增服务商**：点「新增服务商」弹出小窗口，填名称、Base URL、API Key，点「获取模型列表」——列表来自该接口真实返回的 `GET /models`，**不会凭空出现任何模型**。
2. **勾选模型**：弹窗里勾选要保留的模型，保存后出现在外面的服务商表格里。
3. **分别选模型**：设置主页用两个下拉框，分别指定**对话模型**和**图谱抽取模型**，两者可以来自不同服务商。

其他参数：`max_tokens`、`temperature`、超时、结果缓存、数据目录。
「测试所选对话模型」会发一条 16 token 的 ping，确认地址、鉴权和模型名。

配置只写入本机 Zotero 偏好（`extensions.paperloom.*`），不会上传。

## 对话面板

- **右侧常驻面板**：启动后直接挂在主窗口右侧（条目列表 / 分隔条 / 条目详情之后），自带可拖动的分隔条
- **顶部工具栏按钮**：主窗口工具栏上的 PaperLoom 图标，点击显示 / 隐藏右侧面板
- **跟随当前选中论文**：在列表里换一篇，面板自动切过去
- 面板顶栏的「记忆」「图谱」按钮打开对应的全屏视图

## 记忆与图谱的管理

- **记忆**：手动添加 key/value，卡片上可「改正」（锁定为 explicit）或删除
- **图谱**：工具栏可添加概念；点节点后可重命名、删除节点；每条关联边可单独删除
- 设置页新增「全局记忆与图谱」：直接嵌入两个管理页，在设置里就能查看和修改
